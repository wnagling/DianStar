# 2026-10-19

## 天气查询工具

- 新增 `agent_try/tools/weather.py`：按城市名称和日期查询 Open-Meteo，返回目的地当地日期的最高、最低气温（摄氏度）。
- DeepSeek 可以通过 `get_weather` 函数调用读取天气数据；程序将已校验的天气结果直接格式化为回答。
- 首版支持当地今天和之后 7 天；拒绝超出范围的日期，并对重名地点要求补充地区或国家。
- 不使用设备定位或公网 IP 定位。

## 验收

- 20 项离线测试通过，覆盖日期范围、时区、地名歧义、模型工具调用、当前气温及异常工具标记。
- 真实 Open-Meteo 查询已返回北京和柏林当天预报。
- 真实 DeepSeek 对话已调用天气工具，并回答北京当天最高、最低气温及来源。
- 修复潮州提问中模型原样输出工具标记的问题；真实查询已返回潮州市当天最高、最低气温。
- 补充查询当天的当前气温与当地时间；真实潮州查询已输出当前气温、当日最高与最低气温。当前气温标注为模型估计值。
- 根据使用反馈，从终端天气回答中移除固定的数据来源句；来源继续在 README 中记录。

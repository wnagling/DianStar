# 紧凑项目确认（2026-10-29）

问题：普通提交任务让用户批准“调整工具接入范围”，看不出具体操作；展开 JSON 详情让对话框占满屏幕。

## 修正

- 普通模型工具表移除 get_mcp_configuration/configure_mcp，后台功能保留且仅能由可信入口 allow_backend_configuration=True 显式注册。普通任务不能自行注册或更改该入口。
- 新增 open_project：需要切换到已有本地 Git 项目时确认项目名、路径及关联主项目；记住精确项目范围，不改原有功能/审批策略，不提交或推送。确认期间目录关联或配置变化则拒绝；拒绝后不扩大范围。当前项目已有访问能力时不给出重复批准弹窗。
- 底部确认卡按摘要高度自适应，最多 18 行、宽度最多 72 列、背景轻遮罩。详情按钮为一行小入口，切换说明/详情时高度不变；长内容仅在卡片内部滚动，取消与确认不被挤出屏幕。
- 配置类摘要说明实际新增/移除的项目，详情只列变化，不显示未变化的整份 JSON；其他结构化详情转换为可读字段。原始预检字符串和真实执行参数仍由后台保留和绑定。

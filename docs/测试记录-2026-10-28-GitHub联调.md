## 联调发现与修复

1. 官方服务可以启动，但首次文件读取失败。Python 能发现 Windows 系统代理，而官方 Go 服务未得到相应代理环境变量。启动器现保留显式代理，并把缺失的系统代理设置传给子进程；修复后真实读取成功。新增回归保证不会继承其他凭据。
2. 官方文件读取返回 repo://owner/repo/sha/commit/contents/path，搜索精简结果返回字符串仓库及 API 匹配元数据。适配器现从这些可信元数据生成提交固定的 GitHub 文件来源，不解析正文或代码片段中的链接；精简结果中的范围外仓库仍拒绝。新增两项来源与范围回归。
3. 连续写入预览和执行都检查公开性，耗尽代理出口共享的匿名 GitHub API 额度，实际返回 403、X-RateLimit-Remaining=0，导致 CI 详情被拦截。元数据检查现在使用已有 Token 提升认证额度，但每次仍要求 private=false、visibility=public、仓库名称一致；不缓存公开性、不跟随重定向、不因限流放开内容访问。新增认证、匿名、私有/名称不符及错误状态回归。修复后 CI 详情和日志读取成功。

MCP 专项 22 项、GitHub 专项 29 项，共 51 项通过。系统代理修复后的全量 325 项通过；加入真实来源格式修复后全量 327 项通过；加入元数据限流修复后的最终全量为 330 项，全部通过，耗时 141.397 秒。

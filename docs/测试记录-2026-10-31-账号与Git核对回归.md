## 先前失败与限制

最初运行遇到系统临时目录写入拒绝，改用项目内临时目录。受限执行环境中的本机 Git 调用还出现 MSYS 无法创建运行对象的错误，未据此修改 Git 业务逻辑；正常本机权限下的最终发布及 Git/MCP 回归通过。

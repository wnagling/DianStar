# 目录收尾验收

日期：2026-10-27。承接前三步整理，移除迁移期兼容文件，完成根目录归档。

## 实际修改

- `dianstar/` 根目录只保留 `__init__.py`、`__main__.py` 两个 Python 文件；其余实现按职责归入子包，旧路径转发文件已删除。
- 配置拆为 `config/paths.py`、`models.py`、`credentials.py`、`search.py`、`mcp.py`；授权拆为 `security/authorization.py`、`validation.py`、`gateway.py`；工具注册契约位于 `core/registry.py`。
- 会话、来源核验、Windows 剪贴板与复制菜单、欢迎字符画分别移入 `sessions/`、`evidence/`、`platform/windows/`、`ui/tui/art/`。
- 运行时提示词移至 `prompts/system.md`，由 `prompts/builder.py` 加载；Windows 菜单从包资源读取，避免模块移动后相对路径失效。
- 源码、测试及模拟对象均引用真实模块。标准启动命令不变；内部 MCP 服务入口改为 `python -m dianstar.integrations.mcp.git_server`，启动参数与 Windows 打包脚本同步更新。
- `.env`、`.local/` 的位置、配置和会话格式不变，不迁移或重写用户已有数据。编辑器配置未改动。

旧 Python 模块导入路径和 `python -m dianstar.mcp_git_server` 不再支持；如外部脚本曾使用这些内部路径，应按 [当前架构](./架构.md) 更新。

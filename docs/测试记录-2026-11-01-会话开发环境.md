# 会话项目开发环境验收

日期：2026-11-01。范围为公开开发环境的会话持久化与命令复用，不包含自动安装器、后台任务或系统隔离。

## 实现

- `sessions/environments.py` 将配置放入现有 `tasks.sqlite3` 的 `command_environments` 表，联合键为应用传入的会话 ID 和规范化项目路径；无有效会话身份不开放保存工具，不存在匿名共享配置，也不为每个会话创建 JSON 文件。
- `tools/local/environments.py` 提供查询、整体替换和清除。保存公开构建变量及 PATH 前置目录，复用公共内容 Hook；不接受令牌名、启动注入变量或完整 PATH 快照。Windows payload 使用当前用户 DPAPI；POSIX 使用既有私有目录/文件权限。
- `workspace_run` 和 `bash` 自动加载会话项目环境，优先级为本次覆盖、会话项目配置、宿主允许的环境。shell 的 export/cd/source 不自动保存。
- 保存/清除带 `expected_revision`，SQLite 事务完成版本比较与写入；清除仍递增版本，防止旧请求覆盖或恢复。损坏记录停止复用；已保存搜索目录失效时不运行，仍可查询并清除。
- 配置变更与命令使用同一 OS 项目锁；不在审批期间持锁。命令获得项目锁后重做准备，核对环境版本、实际程序及有效环境；不同会话、项目不共享配置。`sessions/task_database.py` 用短 OS 锁保护 WAL/建表首开，同时支持任务日志和环境记录并发初始化。
- 配置不保存或恢复授权，命令审批和后台禁止继续有效；非空保存环境与显式覆盖同样保留默认命令确认。没有新增配置页面。

## 当前边界

复用依据是同一会话 ID，而非每次命令或每次启动；重新进入该会话仍可使用，其他会话不会继承。新建会话需要自己的配置；路径和工具兼容性须重新核验，保存成功不能代替构建验收。不持久化完整 shell 会话、后台进程、凭据或安装许可；程序崩溃和数据库/磁盘故障仍须依据实际状态查询，不能承诺存储设备绝不失效。

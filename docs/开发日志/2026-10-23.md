# DianStar 改名与运行环境调整｜2026-10-23

项目原名 AgentTry（源码目录 `agent_try`、安装包和命令 `agent-try`），现统一为 DianStar。

- 产品显示名称使用 `DianStar`，Python 包名和完整启动命令使用 `dianstar`，保留 `DS` 快捷命令。
- 源码启动方式改为 `python -m dianstar`；启动脚本、资源加载、打包入口、调试配置和测试引用同步更新。
- 最低 Python 版本提高到 3.11，与流式请求使用的 `asyncio.timeout` 保持一致。
- 历史开发日志中的旧名称和旧命令保留，代表当时的项目状态。
- 本次不调整会话文件中模型名称的保存逻辑，该问题另行讨论。

## 从旧安装升级

在安装旧项目的同一个 Python 环境中，先运行 `python -m pip uninstall agent-try`，再在新项目根目录运行 `python -m pip install -e .`。卸载旧安装记录后重新安装，避免旧命令入口和包元数据混用。

`.env`、`.local/config.json` 和 `.local/conversations/` 的位置及格式不因改名改变。移动项目文件夹时须一起保留；源码安装需在移动后重新执行安装命令。便携版继续在可执行文件旁存放这些数据，升级时保留用户自己的数据。

旧 `build/`、`*.egg-info/` 和 `release/` 内容是生成产物，不作为当前源码；新便携包需重新构建。不要把旧 ZIP 当作改名后的验证结果。

首次从旧名称构建普通安装包前，应移开旧 `build/` 缓存；否则 setuptools 可能把缓存中的 `agent_try` 也收入新安装包。本次已将旧缓存移入 `.local/rename-check/old-build/`，重新构建并检查新包不含旧模块。

# 网页工具首版验收

日期：2026-10-25。对应当前 `search_web` / `read_webpage`、搜索配置和运行时提示词；本记录不代表搜索结果质量的全面评测。

本记录按开发迭代顺序保留早期方案与验证结果；当前交互、额度与故障修复以末尾各节为准，已取代手动选择免费／API 服务及每轮四次访问的设计。

## 已实现范围

- 默认免费模式：固定 Bing RSS 搜索结果解析、公开 HTML／纯文本读取与本地正文提取。
- DeepSeek 模式：独立 Search/Fetch API，使用配置中选择的具名 Key，不切换对话模型。
- `/config` 的网页搜索页面可选择免费、API 或关闭；保存到 `.local/search.json`，不包含密钥。未配置的 API Key 不能保存为 API 模式，删除后的 Key 会产生明确配置错误。
- 两个网页工具接入现有注册表、模型工具结果回传及成功会话历史；关闭后不向模型暴露。
- 每轮最多四次网页调用，搜索最多五条、正文最多 16000 字符、响应体最多 2 MiB；超时和结构化错误，不自动切换付费模式或盲目重试。

## 系统代理兼容修复

用户提供浏览器正常访问 Bing 的截图后，检查确认 Windows 配置了系统 HTTP/HTTPS 代理，而网页客户端设置了 `trust_env=False`。使用系统代理请求相同 Bing RSS 地址后，返回 HTTP 200 与 10 条结果，确认为程序连接方式的差异。

修复为两个独立客户端：固定 Bing / DeepSeek 服务继承系统和环境代理，不跟随重定向；任意网页读取仍使用不继承代理的直连客户端，保持 DNS 校验和公网 IP 固定。21 项网页离线测试全部通过，包括新增的代理通道隔离与资源关闭验证。修复后的实际 `search_web` 免费模式成功返回三条含标题、网址和摘要的结果，没有调用付费接口。Bing RSS 的结果相关性和高级查询语法仍不保证与浏览器页面一致，不能只凭 HTTP 成功认定结果质量达标。

此时本地任意网页读取的 Fake-IP 限制仍存在；后续网页读取兼容修复见下节，不能将此中间状态当作当前结论。

## 免费网页读取的 Clash Fake-IP 兼容

修复本地网页读取只支持直连的限制。读取客户端改为继承系统／环境代理；系统 DNS 全部返回 198.18.0.0/15 虚拟地址时，仅向固定 Cloudflare DoH 接口发送域名，查询真实 IPv4 地址。响应限 64 KiB；解析为空、失败、包含内网或保留地址均不访问目标。真实内网和混合 DNS 结果不通过公共 DNS 重试放行，URL 中的受限 IP 仍在解析之前拒绝。

HTTP 请求及代理 CONNECT 的目标为经过验证的公网 IP。由于当前 httpcore 的 HTTP CONNECT 实现忽略请求级 SNI 扩展，对读取客户端使用请求局部的 TLS 主机映射，将隧道目标 IP 的 SNI 和证书主机名恢复成原始网页域名；HTTPS 代理自身不同的主机身份保持不变。证书链与主机名校验继续开启。禁用空闲连接复用，避免同一公网 IP 对应不同网页域名时复用不匹配的 TLS 连接。每次重定向重新执行完整检查；不会访问 Fake-IP 地址本身。

新增离线用例验证 Fake-IP 到公网地址的完整流程、公共 DNS 私网／混合／空／无效响应、DNS 接口重定向与响应大小、真实私网不触发替代解析、代理 TLS 主机身份及映射清理、网页重定向后的目标复查。26 项网页测试通过，最终完整离线回归 156 项全部通过。

真实免费读取复测成功：英文 Dealing with Bugs 页面取得 4652 字符；中文“更多控制流工具”取得 16000 字符并标记截断；中文“数据结构”取得 13886 字符且未截断。本机地址 http://127.0.0.1/ 仍返回 invalid_url。这些复测没有调用 DeepSeek 模型或付费搜索／抓取服务。早期一次中文页面连接失败后复测成功，网络瞬时失败仍可能发生，工具不会因此编造正文。

README、使用指南、工具说明和蓝图同步更新。不修改用户代理设置或已保存的搜索模式，不要求切换付费服务。公共解析依赖固定 Cloudflare 服务可达性；当前备用解析仅查询 IPv4。代理由用户配置并受信任，本措施不等同于 OS 沙箱，也不声称能够抵御本机环境或用户代理遭篡改。

## 免费优先与 API 备用授权

按用户要求将服务选择移入程序：每次优先免费访问，网页挑战、正文提取失败或免费搜索结构异常等候选原因才进入备用判断。网络、DNS、TLS、404、限流、空结果、内网和保留地址拒绝等不触发付费；普通网页权限拒绝也不换服务绕过。备用执行后不再递归重试。

默认付费策略为询问，TUI 弹窗显示具体目标、可能费用与剩余调用预算，可本轮允许、始终允许或拒绝，Esc 拒绝。批准期间暂停并保留当前问题与思考，之后继续同一任务；拒绝后本轮不重复请求。始终允许持久化并可从配置撤回，即使已允许，下一次操作仍优先免费。免费和 API 尝试分别计入每轮四次预算，无预算或无凭据时不弹窗、不调用 API。网页开关与授权策略保存在 search.json，备用 Key 可跟随当前 Key 或另行指定；不更换模型。

旧免费配置迁移为免费优先加询问，旧明确 API 配置迁移为免费优先并保留付费授权；关闭状态保持关闭。配置页不再要求用户手动选择免费／API。纯文本交互支持 y 确认本轮；无交互入口不会在默认询问策略下自行付费。

最终完整离线回归 169 项通过，其中新增 13 项备用与审批测试；最后又验证了思考流更新期间的弹窗、拒绝后再次打开及长期授权保存。首次完整运行在连续弹窗测试处停滞，补充超时后定位到测试在前一弹窗关闭刷新完成前操作下一弹窗，增加刷新同步和点击断言后专项测试通过。未把停滞运行当作通过结果。

用例覆盖免费成功零提示、授权后继续、拒绝不重复、持久允许／禁用、网络和安全拒绝零备用、无凭据、非交互无授权、空搜索结果、预算上限、审批中取消、验证页识别、旧配置迁移，以及 80×24 终端下弹窗按钮可达和问题／思考保留。本轮测试使用模拟网络与假 Key，没有为制造备用场景调用真实付费服务；实际免费与 API 后端的联网验收范围见前述记录。README、使用指南、工具说明、架构和 prompt 蓝图同步。

## 30 次额度与单次提问授权

根据用户反馈，原来的四次总访问预算过低，并将免费尝试也从可用付费次数中扣除。现改为每次用户提问最多 30 次网页操作，以及独立的 30 次 API 备用尝试，免费尝试不占付费额度；每次操作至多免费一次加备用一次，总计至多 60 次访问。弹窗展示剩余 API 额度。网页工具启用时模型决策上限从六次调整为 32 次，允许串行读取 30 页后生成回答；关闭网页工具时保持六次。

“本轮允许”按钮改名为“仅本次提问”，明确提示不会延续到下一次提问；只有始终允许或配置中的自动允许才持久化。检查当前本地配置为旧 free 格式、无 paid_policy，实际加载为 ask；没有发现本次授权跨提问写入配置。网络失败不触发 API，下一轮免费成功或网络失败时不弹窗不等于自动付费。

新增测试模拟同一会话中两次提问各自免费受限、各自通过弹窗回调授权，验证两次分别请求且不生成长期授权配置；模拟完整 30 次付费备用并验证免费／API 合计 60 次尝试，以及第 31 次操作停止；另模拟模型依次读取 30 页后正常生成最终回答。弹窗按钮按实际布局和返回选择核验，不依赖 Pilot.click 在关闭弹窗时不稳定的布尔结果。完整离线回归 172 项全部通过，文档本地链接检查无失效项；本轮未调用真实付费服务，未修改用户保存的授权配置。

## 边界

免费搜索源是网页结果接口，格式和可达性不由 DianStar 控制。免费读取保持公开地址强制检查；不因 Fake-IP 网络而放开内网访问。DeepSeek Fetch 在远端解析域名和抓取，不依赖本机对目标的 DNS 映射，其远端地址／重定向限制依赖服务商实施；仅本机模式能验证固定连接 IP。

本次未全面验收反爬网站、登录页面、复杂动态网页、PDF、图片、论文检索、多引擎排名质量或跨平台真实网络。提示词要求依据实际内容引用并防范外部指令，但不能据此保证模型在所有场景都能抵抗注入或避免误述。

## 无关搜索结果与 arXiv 证书链修复

检查实际会话的工具返回，发现 Bing RSS 收到了正确查询词并返回 HTTP 200，但结果为购物、翻译和软件许可等无关内容；arXiv 读取则因自定义 TLS 上下文缺少普通 HTTPX 使用的信任链而发生 CERTIFICATE_VERIFY_FAILED。不能把这次任务失败概括为两个工具整体不可用。

免费搜索新增保守的英文关键词词面检查，过滤零命中结果，整批无关时返回 search_low_relevance 并申请 API 备用；不承诺语义排序，中文、跨语言和单词查询仍由模型判断。读取客户端改为与 HTTPX 一致的证书来源，保留 CERT_REQUIRED、域名验证和公网 IP 固定检查，明确声明 certifi 依赖。

新增三个回归用例覆盖证书来源选择、搜索噪声过滤，以及真实 RSS 解析进入授权分支后拒绝零付费、同意才发送 API 请求。网页专项 45 项、完整回归 175 项通过。联网复测免费读取 arXiv 2306.05499 摘要页成功，取得 4651 字符；无关搜索进入审批回调，明确拒绝后没有付费请求。该验证不表示已读论文全文，也未验证真实付费备用端到端结果。

## 延后付费备用：先免费探索，再按需续办

修正免费失败即自动进入付费审批的流程。首次 search_web/read_webpage 只免费执行；符合备用条件的失败返回原始错误和随机 api_fallback 标识，让模型先改词、限定来源或读取合理替代页面。已有证据足够时直接回答，不继续补救旧搜索。System prompt 和工具参数说明同步，已有长期授权也不跳过免费探索。

续办仍使用原工具和原参数，加 api_fallback 字段。程序要求当前提问中至少有两个不同的免费目标取得结果或符合备用条件，才能申请备用；同一查询只改条数不算不同目标。该计数不是语义相关性验证，免费替代是否合理、是否还缺必要证据仍依赖模型判断。标识绑定当前提问、工具、原参数和最近一次免费失败；假标识、换目标、跨提问恢复、同目标重新访问后的旧标识和已使用标识均不能发起 API。网络、安全拒绝等不产生标识。审批及结果保留 free_error，解决此前只能看见最终服务而难以定位切换原因的问题。

预算保持最多 30 次免费操作、独立 30 次 API 续办、合计最多 60 次网络尝试；模型决策上限调整为 64，允许免费探索后再逐项续办，不降低付费额度。API 请求仍须现有用户授权，拒绝不重复询问，无预算、无 Key、无确认入口不自行付费。

## 来源获取台账与回答引用核验

新增 source_evidence.py，在编排层记录真实搜索和读取结果，并给模型返回程序生成的 evidence 字段。区分搜索摘要、有限已知站点的摘要页、已知正文页面、一般网页文本与读取失败；标记截断，所有页面均不自动宣称已确认论文完整性。普通文本长度不能证明全文，外部伪造的 evidence 不作为已读证据。摘要识别与正文识别只覆盖明确规则，其他页面保守保留未知全文范围。

最终回答使用 markdown-it-py 解析 Markdown、参考式和自动链接，另识别文本 URL，排除代码和图片。URL 归一化保留查询参数，忽略页内锚点；请求和实际最终 URL 同时记入台账。每个去重后的引用追加获取状态，未命中的引用明确标为未核验，不推断它必定不存在。保留原回答中的链接，不偷偷替换引用，也不声称已做标题、作者、实验数字和结论的语义核对。无引用的普通回答不增加注记。

历史来源只从能匹配工具调用 ID 的历史工具结果恢复，用户文本和历史助手回答不能创建来源证据。历史范围单独注明，失败或后续搜索不抹掉已取得的证据。完成后同步最终可见文本和历史助手回答，保留工具链及元数据；正常会话落盘和恢复无需格式升级。流式草稿仍可能先显示未检查文本，以完成时的核验说明为准。不额外请求模型修订或付费网页服务。

## TUI 网页链接点击与长回答流式显示

修复聊天记录中的 Rich 链接样式没有接入鼠标打开操作的问题。新增 chat_rendering.py，为 Markdown 链接、裸 HTTP/HTTPS 网址以及来源核验行内代码中的网页地址保留链接样式；代码块示例不自动激活。屏幕命中具体链接样式后派发事件，在后台线程通过系统默认浏览器打开，保留原网址锚点，不执行 shell 命令。拖选和右键不触发打开，非公开 HTTP/HTTPS 链接不激活；失败时提示可复制地址。

移除独立八行流式预览框，生成中的回答改为聊天记录中的临时块。按 50 ms 合并更新，已完成逻辑行只追加一次，只重排未结束的一行；结束后在原位置替换为最终 Markdown，保存一次最终回答。工具调用前清除临时说明会停止更新定时器并删除临时块，避免迟到回调和重复回答。未变化的思考内容不重绘整段聊天记录；位于底部时跟随生成内容，向上阅读时保留当前位置，完成时也不强制跳底。生成阶段先显示原始文本，完成后统一排版 Markdown，不宣称复杂 Markdown 在每个 token 到达时都已排版。

新增 6 项专项用例覆盖三类链接点击、代码示例不激活、拖选/右键/不支持链接不打开、百行回答完成前底部可见、向上阅读期间和完成后位置保持、200 次突发文本更新合并、已完成行对象复用、Markdown 只在完成时排版一次、临时说明清理、最终回答不重复及会话保存。浏览器调用全部模拟，没有实际打开浏览器或发起付费请求。

## 长段落流式排版性能优化

用户反馈流式仍有卡顿。使用固定 100×30 的 Textual 离线界面，分别生成约 1000、10000、40000 字符的无换行中英文段落，再连续八次追加少量字符，测量 _paint_stream 同步排版耗时。原实现只缓存完成的逻辑行，无换行段落每帧仍全量折行；同时每个 token 都更新同样的状态栏文字，截断尾部还复制整个历史行列表。

新增 StreamLines，只按显示宽度排版新到字符，已完成显示行复用，尾部未完成行保持在一个显示行范围；支持中文宽字符、组合附加符号、制表符和换行。生成阶段按显示单元折行，可能在英文词中间折行，最终 Markdown 仍统一排版。窗口宽度改变或累计文本改写时重建临时显示。尾行删除改为原地操作；状态栏只在本段回答开始时更新；合并更新频率由每秒约 20 次调整为最多 30 次。

相同基准中位耗时对比（毫秒）：约 1000 字符 0.542→0.109，约 10000 字符 3.623→0.093，约 40000 字符 14.180→0.089；40000 字符样本最大值 43.572→0.129。该数据只测增量排版，不包含模型/网络等待、系统终端刷新或最终整篇 Markdown 排版，不表示端到端延迟降低相同倍数。

新增三项用例覆盖宽字符和组合字符/Tab/CRLF、四万级单段落只排版有限增量且复用已完成行、不重复更新状态栏，以及累计文本改写和窗口调整后的重建。界面专项 33 项及完整回归 205 项全部通过。基准和测试均不联网，不调用模型或付费服务；架构说明已同步。

# 免费检索与过早付费申请修复

## 问题与范围

用户测试“tes今天有比赛吗？”时，Bing RSS 的英文查询被识别为低相关，但中文查询返回游戏首页和无关百科首页，旧逻辑未过滤中文结果。随后低相关英文搜索凭两个免费目标便申请 API 备用。用户拒绝，记录显示未执行该次付费调用。

本次修复通用检索路径和备用资格，不为 TES 或比赛日期写特例，不宣称已确认当天是否有比赛。

## 修改

- 增加固定免费 360 搜索入口，Bing 无有效结果时最多再尝试一个入口；成功后不继续查询其他入口，不混合结果。
- 中文、短英文缩写和混合关键词词面检查；排除仅日期命中和 URL 跟踪参数回显，检查 site: 来源。
- 无关、空结果、格式或网络错误不生成付费搜索标识。两个入口都明确受限才可提供候选，且需要两个不同免费查询；正文读取审批规则不扩大。
- 工具结果增加免费入口尝试状态，保留现有费用、次数、URL 检查和授权边界。
- Prompt 要求围绕对象、别名和具体来源检索，日期判断所需时间仍属于原任务，失败不补无关常识。

## 免费真实网络验证

通过当前系统代理，实际复现 Bing RSS/HTML 对赛程查询返回无关内容。免费 360、搜狗入口能返回相关来源；实现选用 360 作为唯一自动备用。

用修复后的实际工具设置 `paid_policy=deny`，分别查询：

- “英雄联盟 TES 今日 赛程 2026年10月26日”：Bing 低相关后自动用 360，取得赛程相关新闻来源。
- “滔搏 TES 战队 赛程 全球总决赛 瑞士轮”：Bing 低相关后自动用 360，取得对应赛事与队伍的候选报道。
- “Python official tutorial”：取得教程候选；工具的词面匹配不能判断是否官方，Prompt 要求按官方入口或 site: 核对。

以上未申请付费标识，付费调用为 0。搜索候选包含不同日期，仍需模型读取、核对，不能据此直接回答“今天是否有比赛”。没有运行真实对话模型或付费 API 的端到端任务。

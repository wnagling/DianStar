# 后台工具策略与无权限开关界面（2026-10-29）

后续已进一步删除整个 MCP 菜单和设置页面，工具自动接入，见 [透明工具接入](./测试记录-2026-10-29-透明工具接入.md)。下文保留本轮后台策略及当时界面的验收。

## 用户边界

UI 不需要功能权限开关；部分动作仍需用户授权。考虑未来只读/全权限模式，后台可以保留“是否开启”和“是否需要审批”两个独立控制。

## 实现

- MCP 界面移除 Git/GitHub 服务启用、Git/文件/命令写权限，以及 GitHub 写入/管理模式和列表。保留连接程序、凭据来源、Token、项目和目标范围；凭据来源改为账号来源选择，不是功能权限开关。
- 保存连接设置保留已有后台功能策略；删除某个 GitHub 连接范围时同步缩小隐藏写入/管理范围，避免隐藏配置导致无法保存或被扩大。
- ToolPolicy(enabled=True, requires_approval=True) 是可信后台策略，默认工具可用、敏感动作仍需确认。应用入口接受工具名/能力名到策略的映射，工具名规则更具体。
- enabled=false 同时隐藏 schema 并在执行入口阻止动作，不因已有授权或 MCP 重连而绕过。
- requires_approval=false 仅免除敏感动作弹窗，仍调用可信预检，完成参数验证、状态/范围检查和精确单次授权。显式撤销、请求结束和预检失败仍不执行。
- 策略按请求从后端入参取快照，调用方修改原映射不会改变当前请求；不能通过模型工具参数传入。MCP 状态返回实际生效策略，重连和网页工具刷新后重新筛选模型工具。

本次只预留模式后端接口，没有上线只读/全权限菜单或完整模式切换。

- 增加重连策略和隐藏范围缩小后，连同原权限测试：40 项通过（37.612 秒）。
- 增加实际状态反馈后，策略与 UI：13 项通过（8.213 秒）。
- 完整回归：`python -m unittest discover -s tests -v`，400 项全部通过（465.633 秒）。
- `git diff --check` 和 `python -m compileall -q dianstar` 通过。

检查覆盖默认仍审批、禁用覆盖已有授权、受信后端免弹窗仍预检且不保留广泛执行授权、拒绝错误参数/越界预检、显式撤销与请求过期、规则快照和精确规则优先级、实际文件操作、重连后仍禁用，以及 80×24 界面无功能权限控件、保存不改变后台策略、Token 遮挡与清空。所有写操作均发生在临时仓库，GitHub 使用模拟服务，没有修改真实远程仓库或日常权限配置。

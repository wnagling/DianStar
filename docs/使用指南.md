# 使用指南

真实 `.env` 等本地环境文件默认不能通过专用 Git 工具提交或推送；不含凭据的 `.env.example`、`.env.sample` 和 `.env.template` 可以作为模板。正常项目配置可照常编辑，需要在本地配置中保存凭据时请明确说明“仅在本机保存”，确认预览会遮挡凭据。发现敏感内容或检查未完成时先处理问题，不要用命令绕过；命令和克隆后的风险报告不会自动删除文件或改写历史。

底部操作确认卡用中文说明将做什么、操作哪个项目以及保存或发送到哪里。需要核对变更或状态时，点击“查看详情”，再点“返回说明”可回到摘要；卡片保持小尺寸，长内容在内部滚动。取消或按 Esc 不执行。命令行同样先显示操作说明，输入 d 查看详情，再选择是否确认。

本地 Git、项目识别和 GitHub 工具由应用自动接入，设置菜单没有 MCP 项，也不需要先开启工具权限。直接提出克隆、修改、测试、提交或推送任务即可，涉及修改时按后台策略确认。GitHub 通过 `/github` 或设置中的“GitHub 账号”登录，后续自动使用。后台可用性、审批策略及项目范围检查保留，当前尚无只读/全权限模式选择。内部实现与维护说明见 [工具接入](./MCP接入.md)。

切换 GitHub 账号时，若系统凭据库未能清理旧登录，新账号仍可正常保存，界面会提示存在待清理记录。之后在账号页面再次“检查状态”即可重试；退出时也会处理待清理记录。记录只包含账号和 DianStar 自己的凭据库位置，不保存令牌，不清理其他 Git 工具的登录。未清理成功不等于仍在使用旧账号。

返回 [项目首页](../README.md)。以下源码运行命令均在项目根目录执行；首次启动见首页的快速开始。

## 安装与 Key 配置

需要 Python 3.11 或更新版本、可用的 DeepSeek API Key，以及访问 DeepSeek 和 Open-Meteo 的网络。在项目根目录打开 PowerShell：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
Copy-Item .env.example .env
```

然后在**项目根目录**的 `.env` 中将 `DEEPSEEK_API_KEY=your-key-here` 的占位值替换为自己的 Key。这个变量会作为已有的第一个 Key 使用；也可以随后在 `/config` 中添加其他 Key。不要把真实 Key 写入 `.env.example`、README、聊天消息或 Git 提交。安装时使用的 Python 与运行时使用的 Python 应当是同一个环境。

也可在 TUI 中输入 `/config` 设置 Key。进入配置菜单后用 ↑/↓ 选择项目，按 Enter 进入；在 `api_key` 中选择已有 Key 编辑，或选“添加 Key”输入名称和密钥。可“保存并设为默认”；编辑页的“删除 Key”需要再按一次确认，会同时删除其模型配置和 `.env` 中对应的密钥。删除最后一个 Key 后保留一个空的默认配置位置，方便重新设置。编辑页会加载已有密钥，默认以圆点遮挡；点击“显示／隐藏”切换可见性，可直接修改后保存，密钥不能为空。退出编辑后会清空输入框，再次进入时恢复遮挡。所有模型 API Key 均保存在项目根目录的 `.env` 中，配置文件只保存名称、模型和默认选择，密钥不写入聊天记录。

在 `model` 中选中模型后，按 Enter 或点击“编辑选中模型”可修改模型 ID；保存默认模型的新 ID 时，默认选择会同步更新。按 Esc 或“取消”放弃修改。每个 Key 的模型列表独立保存。在 `api_key` 中可点击“编辑选中 Key”修改名称和密钥，只有保存后才会生效。

## 运行、会话与界面操作

GitHub 首次使用时，输入 `/github`，点击“浏览器登录”并在浏览器完成授权。也可以进入 `/config` → “GitHub 账号”。成功后显示账号名，下次提问及后续启动自动使用此登录，不需要每个项目重新登录；项目范围与审批规则保持原样。

若使用访问令牌，点击“输入令牌”，在隐藏输入框填写后“保存并登录”。不要把令牌发到聊天或写入命令参数。页面提供“检查连接”和“退出登录”；凭据保存在系统凭据库，退出不删除其他 Git 工具的登录。

命令行可用 `python -m dianstar --github login`、`--github status`、`--github token`、`--github logout`，无需模型 Key。需要 Git 的登录组件；细节见 [账号登录验收](./测试记录-2026-10-30-GitHub账号登录.md)。

以下命令均在项目根目录运行：

```powershell
# 进入终端界面连续对话
.\.venv\Scripts\python.exe -m dianstar

# 使用原有的纯文本交互界面
.\.venv\Scripts\python.exe -m dianstar --plain

# 单次提问，不保存会话
.\.venv\Scripts\python.exe -m dianstar "潮州今天天气多少度？"

# 按会话 ID 查看和恢复
.\.venv\Scripts\python.exe -m dianstar --list
.\.venv\Scripts\python.exe -m dianstar --resume 会话ID

# 查看命令帮助
.\.venv\Scripts\python.exe -m dianstar --help
```

安装项目后，也可以在任意终端输入 `DS` 启动 DianStar TUI。Windows 命令名不区分大小写；该命令需要安装项目所用 Python 的 `Scripts` 目录位于 PATH。若使用项目 `.venv`，请先激活虚拟环境再输入 `DS`。

### 选择与复制

聊天记录的选择和复制：

- 左键拖选文字，双击只选中当前显示行；右键双击／三击不会触发全选。选区显示为白字蓝底，保留 Markdown 样式。
- 选中后按 Ctrl+C，或在 Windows 上右键打开鼠标旁的深灰色菜单。菜单只显示复制图标和“复制”，不切换页面，不额外显示 PowerShell 任务栏图标。点击外部关闭时清除选区，按 Esc 关闭时保留选区；未选中文字时右键不弹窗、不提示。
- 复制的是显示出的文本。Windows 直接写入系统剪贴板，成功时不提示，仅失败时提示；其他系统沿用 Textual 的终端剪贴板协议和菜单浮层。终端拦截鼠标操作时，可尝试 Shift 拖选及终端自身的复制功能。

菜单会在程序启动后后台预热，后续复用同一进程，减少右键等待；刚启动就操作仍可能等待首次初始化。Windows 原生菜单需要系统自带的 Windows PowerShell 和 .NET Framework。菜单组件的内部实现不会向模型开放命令执行能力。修改源码或菜单资源后，重新启动 DS 生效；已有便携包需要重新构建。

### 多行输入

聊天输入框中，左键双击和 Ctrl+A 都只全选输入框文字，不选择聊天记录；选中后输入会替换草稿。聊天输入框支持多行粘贴，保留换行、空行和缩进；粘贴不会自动发送。按 Enter 发送整段内容，Shift+Enter 或 Ctrl+J 插入换行。输入框最多显示 6 行，更长的内容可滚动编辑。只有单行输入会识别为斜杆命令，多行内容中的 `/new` 等文字按普通消息发送。`--plain` 仍使用原有单行输入方式。

### 会话与命令

连续对话启动后会显示当前会话，输入普通文字即可提问。左侧列表默认收起；点击顶部“显示会话／收起会话”按钮或按 Ctrl+L，可展开或收起。`/switch` 会展开列表并将焦点移过去，用 ↑/↓ 选择，按 Enter 恢复并显示旧聊天记录。Ctrl+B 默认直接切换到下一组 Key／模型，不弹窗；按 Key 配置顺序和各 Key 的模型列表顺序轮换，末项回到首项。不同 Key 下的同名模型分别作为选项，跳过未配置密钥和模型列表为空的 Key；正在回答或配置弹窗打开时不切换。底栏只显示当前模型，不显示 Key 名称或模型切换快捷键。输入 `/` 可查看候选，按 Tab 补全命令。右下角显示当前会话名。在项目根目录双击 `start_dianstar.cmd`，可在独立的 PowerShell 窗口打开界面；脚本优先使用 `.venv`，否则使用 PowerShell 中已安装依赖的 `python`。程序退出或启动失败后窗口会保留，方便查看错误。

| 指令 | 作用 |
| --- | --- |
| `/new` | 创建并切换到新会话 |
| `/rename 新名称` | 重命名当前会话；只输入 `/rename` 会提示输入名称 |
| `/resume 会话名` | 按名称恢复会话；旧的会话 ID 也仍可使用 |
| `/switch` | 聚焦最近使用的会话列表，用方向键和回车选择 |
| `/config` | 打开配置界面：设置 API Key、模型列表、默认模型和快捷键（仅 TUI） |
| `/help` | 显示所有斜杆命令 |
| `/compress` | 清空后续请求的上下文，保留本地记录 |
| `/exit` | 退出程序 |

例如输入 `/resume 北京明天天气`，程序会读取该名称对应的本地会话；恢复后输入的问题会带上该会话尚未清空的上下文。名称完全相同的会话有多个时，程序不会猜选，可用 `/switch` 按时间选择。找不到会话时，当前会话保持不变。旧会话文件没有名称时，会从第一句提问推导默认名称；首次重命名或继续对话后写入新格式。`--plain` 保留旧的数字选择方式，供不支持全屏界面的终端使用。

### 模型与快捷键配置

`/config` 主菜单的各选项使用相同的方框图标。选择 `api_key` 可管理多个具名 Key，并指定一个默认 Key。新建 Key 的模型列表为空；到 `model` 页面选中该 Key，在输入框填写模型 ID 后按 Enter 或点“添加模型”。列表中每个模型占一行，选中后可点“删除选中模型”；增删都会立即保存。`default model` 也可先选 Key，再选该 Key 的默认模型。模型切换快捷键遍历所有已配置密钥的 Key 及其模型，每次同时保存所选默认 Key 和该 Key 的默认模型，下次提问生效；搜索用 Key 仍独立保存，不受此操作影响。“快捷键”页目前有“模型切换”及其输入框；在框内填写如 `Ctrl+B` 或 `Alt+M`，按 Enter 保存。支持 Ctrl/Alt 加字母或数字、F1–F12；与现有操作冲突的组合键会被拒绝。详情页按 Esc 返回菜单，菜单中再按 Esc 关闭配置。删除默认模型时，该 Key 会改用列表中的第一项；删除最后一个模型后，该 Key 不能发起提问，直到添加模型。配置从下一次提问开始生效；模型 ID 只做格式校验，实际可用性由 DeepSeek API 决定。Key 名称、每个 Key 的模型和快捷键保存在 `.local/config.json`，其中不包含密钥。原来的单 Key 模型配置会在首次保存时自动转为新格式。纯文本模式输入 `/config` 会提示切换到 TUI。

### 会话文件

每轮成功问答后才写入会话文件。会话文件位于项目根目录的 `.local/conversations/`，每个 ID 对应一个 JSON 文件；其中保存会话名、可见问答，以及供模型继续对话的工具调用、工具结果和 `reasoning_content`。`/switch` 按文件最近修改时间排序。文件是本机明文，`.local/` 已被 Git 忽略。旧格式会话可继续恢复。长对话会重复发送当前上下文，增加请求内容和费用。

### VS Code 与显示问题

在 VS Code 中打开整个 `DianStar` 文件夹，选中已安装项目依赖的 Python 解释器，再从“运行和调试”使用 `.vscode/launch.json` 提供的“连续对话”“恢复会话”或“提问 DeepSeek”配置。程序应以模块 `dianstar` 启动；直接把 `dianstar/__main__.py` 当独立脚本运行会导致相对导入错误。如果 PowerShell 中文显示乱码，可先运行 `$env:PYTHONIOENCODING='utf-8'`。

### 思考框

每轮按照“问题 → 思考框 → 回答”显示。默认收起为最近四行预览，点击标题展开全文，再点一次收起。工具调用前后的思考合并在同一个框里；后续提问不会覆盖旧框。成功对话的思考随会话保存和恢复，失败请求的部分思考仅保留在当前页面，没有思考时不显示空框。

## 网页访问与 API 备用

回答会在聊天区内持续追加，生成阶段先显示文本，完成后统一排版基础 Markdown。在底部时自动跟随新内容；向上滚动阅读时保留当前位置，不因新内容或回答完成强制跳回底部。

回答里的 Markdown 网页链接、裸网址和来源核验中的行内网址，可以左键单击在系统默认浏览器打开；网页地址会保留页内锚点。拖选文字和右键复制不打开浏览器；代码块中的示例网址不自动激活。打开失败时仍可复制地址后手动访问。

默认无需选择服务：搜索或读取先走免费方式；失败时返回原因，让模型先改词或读取其他合理来源。已有资料足够时直接回答，仍缺必要证据才申请 DeepSeek API 备用。不会要求切换 V4 Pro 或让模型在回答中指导用户切换服务。

免费搜索优先 Bing，结果无关、不可解析或受限时自动尝试免费 360 搜索；首个入口已有可用结果就不多查。程序会做中文、英文缩写与主要关键词的基础检查，限定 `site:` 时核对来源域名。仍然需要阅读原文确认日期、对象和事实，不能把词面匹配当作语义验证。无关、空结果、解析或网络故障不触发付费；只有两个免费入口都明确受限，且已尝试不同查询时，才可能申请付费搜索。

每次搜索默认最多返回 10 条，模型可按需指定 1–20 条，实际结果可能更少。复杂调研会按提示词指导拆分不同侧重点的查询，按需切换中英文、改写关键词或限定来源，再读取候选材料核对证据；简单问题不强制多次搜索。该策略由模型执行，不保证每次调用顺序完全一致，也不增加每次提问的总调用预算。

需要付费备用时，TUI 弹窗显示本次目标、可能产生费用和剩余调用上限，可选择“仅本次提问”“始终允许”“不允许”；Esc 等同拒绝。允许后仍须先免费探索，只在模型明确申请必要的备用续办时用 API；拒绝后本次提问不再重复弹窗。“仅本次提问”不跨提问生效，即使仍在同一会话，下一次需要 API 时也会重新询问；免费成功或网络失败等不触发备用的情况不弹窗，不代表自动付费。选择“始终允许”会保存偏好，之后无需重复确认，可说“撤销付费搜索的始终允许”撤回。

网页权限通过自然语言管理，不再放在 `/config`。例如：“查看当前网页权限”“以后付费搜索先问我”“撤销付费搜索的始终允许”“以后不要使用付费搜索”“关闭网页访问”“开启网页访问”。撤销长期授权会恢复每次提问询问，免费访问仍可使用；关闭网页访问则同时关闭搜索与读取。明确、独立成句的收紧命令可直接执行；复杂表达、开启和扩大权限会先展示具体变更，确认后执行，Esc 取消。当前每轮先处理一项权限变更，再继续研究。保存成功才算修改完成，网页内容和历史回答不能替你授权。备用凭据默认跟随当前 Key，兼容原有独立 Key 引用；免费功能不依赖备用 Key，缺少凭据时不会发起付费请求。详细边界见 [安全机制](./安全机制.md)。

每次提问最多 30 次免费网页操作及独立的 30 次 API 备用续办尝试，免费尝试不占 API 额度；弹窗显示剩余 API 次数。

配置保存在 `.local/search.json`，只包含开关、凭据引用和授权偏好。旧免费配置迁移为免费优先并询问，旧显式 API 配置保留已经允许付费的偏好，但也先尝试免费访问。权限工具保存后对后续操作及提问生效。纯文本交互中可通过 y 确认本轮使用；无交互输入的单次命令在默认询问策略下不会自行付费，除非此前明确设置为自动允许。

网络超时、连接／DNS／TLS 故障、404、限流、没有搜索结果和安全拒绝不会触发 API 备用。不会以备用为由绕过本机、内网或权限检查。

涉及网页链接的回答末尾会附“来源核验”：按首次出现顺序列出各个引用的获取范围。搜索命中只表示取得搜索摘要；可识别的 arXiv / PubMed 摘要页会标为摘要；普通页面仅标为取得网页文本，不能自动认作论文全文。正文页面的截断片段会另行注明，历史工具结果也会标明不是本轮新取得。没有对应成功记录的链接会明确标为“引用未核验”，读取失败也不会算作已读来源。注记随最终回答保存。

核验只检查工具记录与获取范围，不证明来源内容真实，也不自动判断引用是否支持某个实验数字或结论。未知页面类型保持保守标记；未检测到截断不表示已经取得论文全文。流式文本仍是生成过程中的临时结果，以最终回答的核验说明为准。

可测试：“搜索 Python 的官方教程并给出链接。”“阅读 https://docs.python.org/3/bugs.html ，概括提交问题的注意事项并给出来源。”搜索服务不是浏览器，不能登录或提交表单，也不保证读取动态网页、PDF 和附件。

免费网页读取也会使用系统／环境代理。Clash 将域名解析到 198.18.0.0/15 虚拟网段时，程序通过固定 Cloudflare 加密 DNS 接口查询真实 IPv4 地址，验证为公网 IP 后经代理连接；该查询只发送域名，不发送完整网址、网页正文或 Key。普通内网地址或混合受限解析结果不走这条兼容路径。公网解析失败仍会停止，不会放行虚拟地址或自动使用付费服务；没有代理配置时使用直连。免费搜索不跟随搜索接口的跳转，遇到验证页面会报告失败。

## 本地数据与密钥

`.env` 和 `.local/` 已列入 `.gitignore`，因此不会因普通的 `git add .` 进入仓库。第一个 Key 对应 `.env` 中的 `DEEPSEEK_API_KEY`；新增 Key 使用 `DEEPSEEK_API_KEY_KEY2` 等变量。程序会在本机读取当前默认 Key 并通过 SDK 发送请求；DeepSeek 模型收到用户消息和工具结果，不需要收到 Key。**有本机项目文件权限的开发工具仍可能读取 `.env`**；Git 忽略规则不构成访问控制。添加文件工具之前的密钥隔离待办见 [2026-10-21 待办](./开发日志/2026-10-21-待办.md)。

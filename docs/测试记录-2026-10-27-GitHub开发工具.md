# GitHub 开发工具第一、二批验收

开始日期：2026-10-27；验收完成日期：2026-10-28。

## 实现范围

原有 12 个读取工具扩展为 19 个读取工具、7 个写入工具。补充仓库树、代码/Issue/PR 搜索、工作流/运行/任务及日志，PR 提交列表和 check runs；补充创建/更新 PR、创建/更新 Issue、评论、待提交审查、行级/文件级评论、回复和审查线程处理。

正式参数沿用官方 Schema；方法与允许集合取交集，不为 search_code 增加 owner/repo，保留官方可选参数、类型和必填项。修复 Schema 文档清理误删 title 正式属性的问题；空正文按官方语义允许清空内容。旧配置默认仍为公开只读，私有访问和写操作是允许仓库的独立子集。

写操作接入已有 ToolGateway：范围检查、预览、精确参数单次批准、状态重查与实际调用。预览 10 分钟有效、每轮最多 30 次；拒绝、无确认入口、撤销、过期、参数/状态变化不执行。跨仓库父 Issue、回复目标及审查线程核验所属仓库和 PR。网络超时或取消后的写结果不明，不自动重试。远程检查与写入不是原子操作，仍不能消除所有竞态。

配置页新增私有/写操作仓库列表，保存/测试/返回按钮固定于底部，内容区域单独滚动。Token 默认遮挡，保存或退出清空，保存配置不自动启动服务。提示词、首页、架构及使用说明同步。

## 分阶段测试

1. 配置及工具分类：原 MCP 21 项通过，包含真实本地 Git stdio。
2. GitHub 专项：24 项通过，覆盖官方 Schema、搜索 Boolean 范围与越界结果、CI 方法、私有凭据、完整写入参数、逐次批准、状态变化/过期、超时及跨仓库引用；包含跨 fork PR 的 compare API 分页及当前账号待提交审查、全部评论的分页预览。
3. 配置 UI：2 项通过，包含 80×24 下布局、完整配置保存、Token 遮挡清空及不隐式启动。

完整模型消息链路以模拟响应运行：搜索 → CI 运行/任务 → 日志 → 草稿 PR → Issue → 待提交审查 → 行级评论 → 回复 → 提交审查 → 更新 PR → 最终回答。共 12 次模型决策、11 次工具调用、7 次写操作审批，工具参数和消息历史逐项验证。

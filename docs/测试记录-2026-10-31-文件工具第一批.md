# 第一批文件工具验收（2026-10-31）

## 范围

实现 `read + glob + grep + edit + write`，作为独立本地工具统一经 ToolGateway 执行。`read` 也列目录，`write` 负责创建文件和父目录。既有 `workspace_delete`、`workspace_run` 保留；本批不实现 patch、多文件事务或操作系统沙箱。

旧的 workspace_read/list/search/edit 不再提供给模型，后台旧策略保守迁移，禁用和审批要求不会因改名放松。模型工具定义、运行时提示、项目重连清理及状态展示同步更新。

## 结构与保护

- `tools/local/workspace.py` 保留已接入项目范围、路径检查与组装；`commands.py` 承接既有命令能力。
- `tools/local/files/` 拆分定义/入口、读取与目录发现、文本快照与写入，搜索使用固定程序资源 `search_worker.txt`。
- `hooks/workspace.py` 新增 `before_read`，公共令牌检测继续复用 `security/content_guard.py`。真实环境文件、私钥与应用本地目录不作为普通读取结果；普通源码的敏感值先脱敏再返回或搜索，保留原行号。
- 写入在预览前与执行前调用 `before_write`，失败和 Hook 异常均拒绝执行；后台免弹窗策略不会跳过检查。
- 已有文件须本轮成功读取，修改前和审批后核对完整快照；精确替换默认唯一匹配。保留 BOM 与原换行风格，写入使用同目录临时文件，新建遇到并发创建不覆盖。
- 路径拒绝越界、链接、硬链接和 Windows 特殊别名。取消不创建目标目录；替换失败保留原文件并清理临时文件。
- Git 项目发现工具尊重忽略和否定规则，搜索明确报告跳过、截断及失败。正则固定子进程五秒超时，拒绝把超时当作没有匹配。

Hook 不额外增加确认次数。读取/搜索默认不弹窗，实际修改按现有后台策略处理；不新增 UI 权限开关。

## 真实模型调用

调用当前配置的真实模型和 DianStar `run_turn`，在 `.local/file-tools-live-20261031/project` 隔离 Git 样例中完成：

1. glob 定位 `src/settings.py`。
2. grep 搜索 `TIMEOUT`，忽略目录中的干扰文件不纳入搜索。
3. read 读取源码。
4. edit 将 `TIMEOUT = 10` 改为 `20`。
5. write 创建中文说明文档，并回读核对。

两个写操作各批准一次；读取和搜索没有增加确认。实际字节核对 BOM 和 CRLF 保留，干扰文件未修改，没有运行命令、暂存、提交或推送。该验证使用限定样例路径的自动审批回调，不能表述为人工点击 UI 验收。

首次验收脚本遗漏允许模型调用 `open_project`；实际返回是 `project_already_open`，没有新增权限或写操作。修正验收允许列表后，依据已保存的真实调用记录和实际文件重新校验通过，没有为此重复修改文件或再次调用模型。

## 边界

仅支持有界 UTF-8 / UTF-8 BOM 文本，不自动转换其他编码或二进制。单文件 2 MiB、搜索总量 32 MiB、候选 10000 项、单页最多 500 项；结果和单行片段有上限。非 Git 目录存在无法准确解释的忽略规则时明确失败。

源码模式真实调用与打包入口的搜索协议及哈希校验已测；没有重新构建 Windows 可执行文件。路径复查及单文件原子替换不能承诺消除所有系统调用竞争窗口，Hook 也不等于文件系统或网络隔离。多文件补丁与事务恢复留待后续。

# DianStar

DianStar 是一个基于 Python 和 Textual 的终端 Agent 项目，支持流式对话、会话恢复和工具调用，正逐步完善为通用 Agent。

目前接入 DeepSeek，提供网页搜索与读取、天气查询、日期计算和数字计算。你可以在终端连续提问、查看每轮思考内容，也可以恢复之前的会话继续交流。

## 快速开始

需要 **Python 3.11 或更新版本**、DeepSeek API Key，以及访问 DeepSeek 的网络；天气查询还需要访问 Open-Meteo。以下为 Windows PowerShell 的源码安装步骤，在项目根目录执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\python.exe -m dianstar
```

启动后输入 `/config`，在 `api_key` 中设置自己的 Key，再确认该 Key 的默认模型。首次安装预置 `deepseek-flash` 和 `deepseek-v4-pro`；新建 Key 后需在 `model` 中添加模型并选择默认项。配置完成后即可提问，例如：

```text
潮州今天天气怎么样？
2028 年 2 月 28 日过两天是哪天？
本金 100 元，每年增长 5%，三年后是多少？
```

激活虚拟环境后，也可直接使用快捷命令：

```powershell
.\.venv\Scripts\Activate.ps1
DS
```

如果环境不允许激活脚本，继续使用上面的完整 Python 路径启动即可。其他启动方式、手动配置 `.env`、多 Key 管理和常见问题见 [使用指南](./docs/使用指南.md)。

## 核心功能

| 功能 | 当前支持 |
| --- | --- |
| 连续对话 | 回答在聊天区内流式追加，完成后排版 Markdown；支持多行输入与粘贴 |
| 网页链接 | 点击回答中的网页链接、裸网址或来源核验网址，在默认浏览器打开 |
| 思考展示 | 每轮独立思考框，位于问题与回答之间；默认预览最近四行，点击标题展开全文 |
| 会话管理 | 本地保存、重命名、切换与恢复；恢复时显示已保存的对应思考 |
| 模型配置 | 多个具名 Key、各 Key 独立模型列表及默认模型、快捷切换 |
| 天气查询 | 查询地点当地的今天及未来 7 天，按问题提供温度、降水等信息 |
| 日期计算 | 星期、按天加减、日期差和指定时区的日期 |
| 数字计算 | 十进制加减乘除、括号、科学计数法和整数次幂 |
| 网页检索 | Bing 不可用时自动尝试免费 360 搜索；默认 10 条、最多 20 条；无关结果或解析失败不触发付费；必要的受限访问单独审批 |
| 网页权限 | 自然语言提出变更，独立流程处理；明确撤销可直接生效，复杂表达和扩权先确认；网页不能修改授权 |
| 工具授权 | 所有工具执行前检查能力、参数、范围与额度；本轮授权独立于对话资料，新能力默认拒绝 |
| Agent 循环 | 每次提问最多 16 轮模型决策，包含最终回答；每批最多 8 个工具，同名同参数可按需重复执行 |
| MCP 接入 | 本地 Git 工程操作；GitHub 仓库浏览、代码/任务搜索、PR、Issue、CI 日志和代码审查；在 `/config` → MCP 中配置仓库范围，私有访问和写操作分别启用，写操作逐次确认 |
| 来源核验 | 核对引用是否来自工具记录，区分搜索摘要、论文摘要页、网页文本及截断片段；不等同于事实核查 |

工具参数与限制见 [工具说明](./docs/工具说明.md)，界面和配置细节见 [使用指南](./docs/使用指南.md)。授权流程、攻击防护及当前局限见 [安全机制](./docs/安全机制.md)。

## 常用操作

| 操作 | 作用 |
| --- | --- |
| Enter | 发送整段输入 |
| Shift+Enter / Ctrl+J | 插入换行 |
| Ctrl+A / 输入栏左键双击 | 全选输入框文字 |
| 左键拖选 / 聊天区左键双击 | 选择聊天文字 / 当前显示行 |
| Ctrl+C / Windows 选中后右键 | 复制选中文字 / 打开复制菜单 |
| Ctrl+L | 展开或收起会话列表 |
| Ctrl+B | 直接切换下一组 Key／模型，不弹窗；遍历所有已配置密钥的 Key，快捷键可在配置中修改 |
| Tab | 补全斜杆命令 |

| 指令 | 作用 |
| --- | --- |
| `/new` | 创建并切换到新会话 |
| `/rename 新名称` | 重命名当前会话 |
| `/resume 会话名` | 恢复会话，也支持会话 ID |
| `/switch` | 打开会话列表，用方向键和回车选择 |
| `/config` | 管理 Key、模型、快捷键和 MCP 服务，仅 TUI 支持 |
| `/compress` | 清空后续请求使用的上下文，保留本地聊天记录；当前不生成摘要 |
| `/help` | 显示命令帮助 |
| `/exit` | 退出程序 |

斜杆命令仅在单行输入时识别。单次提问可使用 `python -m dianstar "你的问题"`，纯文本交互可使用 `python -m dianstar --plain`；这里的 `python` 需来自已安装项目的环境。

## 当前边界

- 输入仅支持文字，暂不支持图片上传和附件解析；粘贴文件路径不会自动读取文件。回答支持基础 Markdown，不提供图片、HTML 或交互组件展示。
- 尚未提供通用本地文件读取、文件修改、任意命令执行、日程保存或定时提醒工具。Git MCP 支持配置范围内的工程操作；GitHub MCP 支持指定仓库的查询与开发协作，私有访问和写操作单独配置，写操作展示预览并逐次确认。pull、merge、强制推送、冲突修复和 worktree 尚未开放。
- 日期和数字计算在本机执行，但由模型选择工具仍需联网。天气地点由用户提供，程序不读取设备位置或按 IP 推断位置。
- 模型可能选择错误工具、列错表达式或误述结果；程序的参数校验与调用上限不能保证回答始终正确。提示词规则不能替代访问控制。
- 免费搜索受搜索站点访问限制和格式变化影响，不保证可用；网页读取支持系统代理及 Clash Fake-IP，取得并验证真实公网 IP 后连接，仍拒绝内网和保留地址。必要的 DeepSeek API 备用单独计费，默认在使用前询问；可仅允许本次提问、始终允许或拒绝；每次提问最多 30 次网页操作，API 备用另有独立的 30 次额度。网络故障、安全拒绝及没有搜索结果不会触发付费备用。详见 [工具说明](./docs/工具说明.md#网页搜索与读取)。
- Key 保存在本机 `.env`，配置和会话保存在 `.local/`；会话包含问答、思考和工具消息，均为本机明文。这些路径已被 Git 忽略，但仍可被有相应本机权限的程序读取。长对话会重复发送当前上下文，增加请求内容和费用。

## 开发与测试

安装源码依赖后，在项目根目录执行：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests
```

离线测试使用模拟的模型与天气响应，不需要真实 Key；通过离线测试不代表真实服务调用已验证。联网天气批量检查和既有验收结果见 [开发与测试](./docs/开发与测试.md)。

项目原名 AgentTry，现使用 Python 包名 `dianstar`，启动命令为 `dianstar` 或 `DS`。改名与升级历史见 [开发记录](./docs/开发日志/2026-10-23.md)。

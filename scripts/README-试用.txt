DianStar Windows 试用版

1. 解压整个 ZIP 文件，双击 DianStar.cmd（也可直接运行 DianStar.exe）。
2. 在程序中输入 /config，进入 api_key，填写自己的 DeepSeek API Key。
3. 默认 Key 已有预置模型；如果新增 Key，请到 model 页面为它添加模型。
4. 返回对话界面，输入问题即可开始使用。查询天气需要联网。

请勿把自己的 .env、.local 文件夹或 API Key 发给别人。
程序会在解压目录生成 .env 和 .local 文件夹，分别保存密钥与会话。
分发包不包含 Python，也不包含制作者的密钥或会话。
